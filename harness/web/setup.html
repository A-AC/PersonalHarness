First-run setup

This harness has no saved configuration yet. Set the access token and the model endpoint to finish installing it. The same values can be provided non-interactively with harness init and the HARNESS_* environment variables.

Access token

Protects the UI and API. Use a long random value and keep it private.

Model endpoint

Check the connection to list the models the endpoint advertises, then pick one. The endpoint must be reachable from inside the container.

Timezone

Leave as system to use the container clock. Set TZ or this value when the clock is UTC but you are not.
