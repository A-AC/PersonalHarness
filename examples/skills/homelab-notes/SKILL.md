---
name: homelab-notes
description: Keep homelab changes short, reversible, and tied to evidence.
preconditions: homelab
---

When the task concerns the homelab:

- Prefer a read or status check before proposing a change.
- State the target host and the expected effect in one sentence.
- Never imply that a change was applied without a succeeded execution envelope.
- If an outcome is unknown, stop and ask for reconciliation instead of retrying a write.
